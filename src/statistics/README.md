# Statistical and numerical applications

These implementations expose the
[statistics interface](../../include/gadget/statistics/README.md).

`pathways.cpp` admits native owners and declarations. `pathway_ora.cpp` binds
mapping and membership occurrences to a uniform subset law, delegates finite
calibration and applies the declared multiple testing policy.

`execution.cpp` prepares contextual operators and delegates binary64 solves to
RexGraphCPP. `query.cpp` admits and runs contextual queries. `analysis.cpp` retains
their native fields, numerical diagnostics and reports.

Native scientific operations and canonical mathematical providers retain their
existing interfaces. Shared storage, scheduling and resource admission remain
owned by their existing providers.
