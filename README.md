# biomed-gadget

biomed-gadget is a C++ library and command line application for biomedical data
analysis. It connects measurements, biological context and mathematical models
while retaining source identities, observation support and the steps that
produced each result.

The library supports declared relations, sequence and assay queries, field
analysis and reproducible data workflows. Mathematical operations and native
formats use the independent RexGraph libraries.

See the [installation guide](https://github.com/sirtrott1/biomed-gadget/blob/main/DEPENDENCIES.md)
and [examples](https://github.com/sirtrott1/biomed-gadget/blob/main/examples/README.md).
